# .github

Shared assets for the Vanguard Cloud Consulting organisation profile.

| Path | Contents |
|---|---|
| `profile/assets/header.png` | Logo and wordmark banner used at the top of the organisation profile |
| `profile/assets/org-avatar.png` | Square logo for the organisation profile picture — upload via **Settings → General → Profile picture** |

Assets live here, in a public repository, because GitHub's image proxy cannot
authenticate to a private one — an image served from a private repo renders as a
broken image wherever it is referenced.
